# 一屏展示外壳取代纯流式布局

App 端最初按 P0 设计方案 §8.1 / R15 DR15-8 采用"纯流式、零媒体查询、零缩放"适配（基准 390×780）。真机为 19.5:9 长屏（如 iPhone 15 Pro 393×852），内容稀疏页面被流式拉伸后留白过多（#40），故改为**一屏展示**外壳：`.app-shell` 锁 `100dvh` + flex 纵向三段（顶栏 / 内容区 `flex:1` 滚动 / 底部操作栏），全程不使用 `position: fixed`；顶栏不全局化，StarNavBar 留在页内普通流，锁高后视觉等效固定。

## Considered Options

- **fixed 顶/底栏**（否决）：横跨全屏与 480px 居中容器冲突，需居中补丁；滚动容器一旦出现 transform/filter 会让水印、弹窗、toast 的 fixed 错位（containing block 陷阱）。
- **顶栏全局化到壳 slot**（否决）：需改 11 页模板 + router 嵌套 + 重写 Home/Quiz 测试断言；页内流式顶栏在锁高后视觉等效，改动面差一个量级。

## Consequences

- 桌面端与移动端统一为"内容区内部滚动"，页面外层永不滚动。
- P0 §8.1 与 DR15-8 的"纯流式"决策自此失效，由本 ADR 取代。
- 底部操作栏仅用于有页面级主操作的页面（答题、编辑提议、结果页）。
- 跨页滚动容器四件套与底栏样式集归宿 components.css（.page-scroll / .bottom-action-bar，#68 收编）。
- 操作页 edit/result 滚动容器为三件套变体（无 overscroll-behavior: contain），是否统一待有意拍板（#68 注记）。
