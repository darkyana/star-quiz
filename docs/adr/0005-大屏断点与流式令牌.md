# 大屏断点与流式令牌：宽断点三阶段外壳 + 字号族 clamp 流式

> **编号说明（2026-09-20）**：与 `0005-同步域D1库表定稿与逃生舱契约门禁.md` 重号（历史遗留，暂不重号）。全仓「ADR 0005」引用凡涉同步/库表皆指那份；本文只涉大屏断点与设计令牌。

iPad 上全 app 呈现「放大版手机 UI」（#155）：字号/尺寸令牌全固定 px 手机档（设计基准 390 宽），外壳单阶段 480px 居中，除 `hover`/`prefers-reduced-motion` 外零媒体查询。经两轮 grilling 拍板（纪要见票内评论区），采用**方向 B：外壳加宽 + 令牌微调**，并把语义定为「布局规则全宽统一，设备差异只是落在不同宽度阶段」——不按设备型号、不按 orientation 分端。

## 决策

- **字号族流式化**：两侧（App 与 xingxing-parent）`--font-size-*` 全族从单一 px 改为 `clamp(下限, 线性插值, 上限)`：下限 = 现值（390px 视口渲染值与改前相等，手机观感不变）；上限 = 现值 × 1.12 四舍五入到整数 px（1366px 视口触顶）；插值按标准 slope 公式，视口对 390/1366。
- **外壳三阶段**（修订 2026-09-06，#156）：视口 <600px 时 `.app-shell` 上限 480；600–1023px → 640；≥1024px → 760。居中方式不变；宽度断点，orientation 无关。600 取自内容经验值（单列内容超过 600 即显空旷），760 为 iPad 横屏内容列经验值（配合选项两列与 CJK 阅读行宽上限），均非设备型号值。
- **宽档答题两列**（#156）：视口 ≥1024px 时答题选项 2×2 两列（跳过整行次要位；行高保持触控 md 档热区不缩；每列 ≥340px 下限）——单页特例，归宿页面 scoped。
- **反馈可见性行为兜底**（#156）：答题判分后反馈条最近距离滚入可视区；系统开启「减弱动态效果」时免动画滚动。既有决策「反馈文案留内容区」不动。
- **恒定面**：触控档（44/56）、间距、圆角、图标、星星尺寸、字距、阴影/发光全宽恒定——缩的是字号与布局观感，不缩触控热区。一屏外壳三段结构与「内容区唯一滚动」不变。

## Considered Options

- **离散分档**（多断点跳档字号，否决）：令牌表按档翻倍、档间跳变生硬；clamp 一表贯通且钉测表达力相当。
- **orientation 横屏断点 / 设备型号分端**（否决）：拍板宽度型单档；分端违「全 app 统一（含家长端）」拍板。
- **只缩控件尺寸不动令牌**（否决）：触控热区底线（sm 档 44px）不破是硬约束，缩观感须走字号/列宽而非热区。

## Consequences

- ADR 0001 的「零媒体查询」语义自此修订为「宽度断点恰两条：外壳 600px / 1024px 阶段」；一屏三段结构结论不推翻。
- 手机档（390 基准）渲染值由 clamp 下限锚定，观感零变化；样式测试钉子从「钉单一 px」改为「钉 clamp 表达式与三阶段表」。
- 家长端外壳（xingxing-parent 960px）为桌面工作台形态，暂不套阶段表——已拍板（2026-09-06，老板）：家长端将纳入宽度阶段体系，落地另行建票；纳入前维持现状。
- 控件宽度封顶（按钮/卡片大屏不无限拉伸）不在本决策内，切 follow-up 票；答题反馈条可见性由 #156 修复（宽档两列 + 滚入兜底）。
- 真机对照（iPad Pro 13 级别 standalone 横竖屏 vs 390×844）为验收期人工项。

## 修订记录

- 2026-09-06（#156 验收合并）：两阶段 → 三阶段（增 ≥1024 → 760），增补宽档答题选项两列与反馈滚入兜底。动因：#146 星夜字阶（题干 34px 档）+ #155 大屏体系落地后，iPad Pro 11 横屏答题页高度超一屏、反馈条稳定落在折叠线以下（老板真机坐实）。
