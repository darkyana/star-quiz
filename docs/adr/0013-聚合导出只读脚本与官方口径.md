# 聚合导出——只读脚本、官方口径与 family_id 锚定匿名 ID

增长侧要「家庭 × 自然周」的匿名聚合计数（G-001/#229）。决定不新增任何端点与埋点：聚合 SQL 与匿名 ID 派生随仓落在 tools/ 只读脚本（沿 operator.mjs 的 wrangler 通道），运营方本机自助导出；口径连同降级（导入无云端痕迹故不交付、提议只有最终状态、批准时刻不可考仅 paired_at 近似）写进随脚本交付的口径文档，输出仅周桶计数、无逐题明细与日内时间戳——官方口径进仓，堵住临时查询误用逐题明细。

匿名 ID 锚定 family_id（终身不变）而非家庭码（可重置，哈希即断链）：sha256(固定前缀 + family_id) 截断 16 位。已知边界明写：家庭由运营方发码创建、发码台账可反查，匿名保证的是导出文件本身无可识别字段，不针对运营方。

## Considered Options

- Worker Cron 预聚合表 / HTTP 导出端点：每周一批的频率下属过度设计，且公网新增可探测面，败给零新增面的只读脚本
- 匿名 ID 派生自家庭码（cx ADR 0007 原案）：码重置即断链、跨周追踪失真，已随票建议对侧改锚 family_id
- 为「导入次数」加客户端动作痕迹：违反本期零改动红线，家长周导入率继续走问卷
