## 断代批次备注（8→9，一次带全；#173 上篇已落地）

1. 数据行加 childId（默认孩子 `'default'`，常量单点 src/types/index.ts DEFAULT_CHILD_ID）：星星流水 / 提议 / 进行中兑换 / 红旗条目 / 逐题记录 / 临场状态；近期已测词为字符串数组无处挂维度、兑换目录与题池全家共享不挂（Spec 缺口见 #173 交付报告）。
2. 流水加 kind 星种列（'main'|'game'|'interest'，缺省主星）；兑换项可带 requirement { kind, amount } 星种附加要求。
3. 题池加大类/分册（category/book，缺省 '学科'/'默认'，常量 DEFAULT_QUESTION_CATEGORY/BOOK）、wordId 可空（trivia 题）、type 加 trivia。
4. 近期已测词改形字符串数组（新→旧，上限 30，常量 RECENT_WORDS_LIMIT）；抽题引擎按清单成员判窗口、移除旧第二层（久未出优先）排序——清单外词公平轮转（#166 模型决议 4）。
5. sq_proficiency → sq_morale 改名整搬（迁移 8→9）；引擎域映射演进属 #177。
6. 导出契约升位：学习文件 '2.0'→'3.0'、经济文件 '2.2'→'2.3'；上一版文件兼容导入、新字段按默认补齐。迁移前备份或旧云端行导出时同样补齐副本，不改写源数据。
7. 词清单的旧同步影子（sq_sync_shadow.word_appearances）同捆转换成数组，保留其他域与游标，避免旧对象被当成数组；不等于完成全域同步重基线。
8. 断代迁移体验单列一票 #174（迁移无感/备份落地/同步重基线）；引擎语义演进（D1 合并键、按分册调度、不混抽、morale 域映射）属 #177。本票新增形状不代表多孩子/星种兑换规则/惊喜题隔离已接线。
9. 抽题种子金样覆盖旧排序不产生差异的 60 个基线场景；删去久未出优先并改用固定 30 词后，不能承诺任意历史均与旧引擎同序。同步仍沿现有 word_appearances 协议做成员合并，不保留旧设备轮次计数。
