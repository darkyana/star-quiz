## 已确认方向

参考 App 首屏 Mini Garage 入口贴纸，不参考游戏内部素材。短胖圆钝五角星，轻微不对称，大问号正向；简单可爱、大色块、轻微纸感，无表情、四肢、散落装饰或新增动画。通用惊喜意象，不绑定 Minecraft。颜色不用与小汽车相关。先首屏看效果，再决定颜色；未获批准前不改正式资源或入口逻辑。

## 预览条件与边界

当前源代码由 Vite 在本机提供；独立 Playwright context，不连接用户浏览器，不使用用户存储或云数据。28 星是模拟余额。临时显示现有小汽车入口，隐藏即将由 #269 替代的旧惊喜区，克隆入口外观并在小汽车左侧注入候选图片。两入口热区均 44px、间距复用 12px 令牌，作为视觉摆放提案，不代表 #269 已实现。手机 390×844、桌面 1280×900，DPR 2。未修改 src/ 或 public/。

首页背景已有的星子仍在截图中，不是新贴纸自带装饰。放大细节图不加外描边；首页截图沿用现有宿主八向 drop-shadow，未另做描边规则。

## 画作来源与处理

`generated-original.png` 是本会话 Codex Connect image generation 生成的原始 PNG，原样复制保存。原始附件 SHA-256：117a05aff259f7eb24afae9df5c5415391530367568b7c38fa2c7eed73eed785。

生成提示：单个简单可爱的胖圆五角星，紫色主体，中央大号奶油色问号；五个短胖圆角、轻微手作不对称、平面大色块与极轻纸感；44px 仍清晰；禁止脸、眼睛、四肢、小星星、外描边、阴影、浮雕、3D、高光、其他文字或汽车。

`build-preview.mjs` 保留原图透明度与问号，按主体色像素变换得到三种颜色，统一缩放及透明留白，输出 PNG 与自包含内嵌 PNG 的 SVG；没有重画三套不同形状。`build-review.mjs` 打包自包含 HTML 和对比 PNG。脚本使用本机已有 Playwright；重跑需启动当前项目 Vite 5173，原始附件路径写在脚本中。
