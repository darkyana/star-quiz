## 视觉方向

**暖白 + 珊瑚橙 + 深青玻璃，明亮的机器人装配工作台。**

- 小车：奶油白车壳、珊瑚橙装甲、深青玻璃、黑灰橡胶、暖金属轮毂/接口。避免幼儿化表情、恐怖元素和霓虹轰炸。
- 首页：小车是主角；先看路线再选择轮胎/装置，选中反馈克制清楚，主按钮与车身强调色一致。
- 赛道：灰绿路面配暖白外框，桌面木纹与机器人小机械臂作为外围装饰，不抢路线信息。
- 语义不变：橙白路障需要规避，蓝色箭头跳台可借台起跳，紫色凸起缓速带必须容易与路面分开辨认。
- 面向 iPhone 的单列；iPad 保持同一单列并限制最大内容宽度 460px，不恢复左右分栏。

### 令牌、样式与组件边界

遵循小游戏接入约定：自包含，不依赖宿主样式/组件。此样板使用自己的 CSS 令牌（paper / ink / coral / teal / sage / muted / line 等），首页卡片、部件选择、评审切换、HUD、控制按钮均为样板私有原生控件；SVG 材质渐变/几何为游戏美术数据，不改主产品设计令牌、组件注册表或页面样式。

这次没有接宿主、账本、存储、Service Worker、外部字体或 CDN。全部运行资源使用本目录相对路径。

## 可交互范围与明确限制

- 可切换三条路线的首页信息、两种轮胎和两种装置；选中样式与配置摘要同步更新。
- 主视觉是固定车型形象图，选零件不会实时重绘主图。页面已明确说明，不伪装成已经完成实时装配。
- 赛道视图固定展示跳台工坊的代表性构图，首页改选其他路线不会生成另一张赛道；标题明确标注“代表性赛段 · 非游玩画面”。路线小缩略图也是示意，不是实际关卡地图。
- 控件演示小车横移、腾空/阴影变化、喷口反馈，可暂停/继续；两指转向与装置可并用。不会推进真实比赛、判断碰撞或记分。
- HUD 的 00:42、86 km/h 等是构图示意，不是用户成绩。原有游戏速度曲线、关卡布局、装置规则、生命周期边界全部没有修改。
- 底部深青切换条是视觉评审工具，不属于最终给孩子的游戏界面。
- 仍不具备生产付费授权能力；正式接入必须沿用 main 的 `public/games/README.md` 契约。
