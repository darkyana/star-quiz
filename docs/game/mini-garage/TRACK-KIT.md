## 统一制作规格

| 层次 | 约束 |
|---|---|
| 视角 | 正俯视；车头、跳台通过方向朝上；不混用斜视道具 |
| 光照 | 左上柔光；高光柔和，接触阴影向右下；车辆离地阴影独立 |
| 材质 | 象牙白塑料、珊瑚橙烤漆、深青玻璃、暖金属、橡胶 |
| 细节预算 | 车辆保留车壳接缝/玻璃/胎纹；组件有倒角/紧固件；路面是微纹理，不铺满道具 |
| 辨识 | 橙白障碍、蓝色跳台、紫色缓速带保持既定语义 |
| 接地 | 路沿采用真实材质片段；缓速带开放两端、贯穿道路；跳台使用渐薄楔形侧壁与随高度变化的投影，不再保留钉装外框 |
| 样板尺寸 | 390×650 SVG 场景坐标；车辆 66×90、路障 81×29、跳台 100×136；缓速带高 68、超宽绘制 336 后裁切到宽约 248 的道路；这是美术组装尺寸，不是新增碰撞框 |

令牌/样式/组件：沿用原样板 `--paper/--ink/--sage/--line` 等令牌，不变更宿主。新增素材格、材质格、效果格为样板私有原生组件，样式收在相邻 `track-kit-preview.css`；道路/纹理/光照属于样板自绘美术数据，组装收在 `track-kit-preview.js`。继续复用原有选择、控制、视图切换和暂停机制。按用户指定的同套材质目标制作，没有擅自新增三套互斥设计方向。

## 资源清单与使用

精确尺寸、角色、原图 SHA-256 见 `art-assets/track-kit/manifest.json`。运行素材共 **1,907,516 字节（约 1.82 MiB）**，不包括原图、截图和说明。

- 4 × `car-{road,offroad}-{boost,jump}.png`：296×400 RGBA，固定同一裁切画布，中心锚点。纯色背景按边界连通去除，并处理边缘色溢；没有把四张分别自适应裁切造成明显尺寸跳变。
- 4 × `surface-{road,sand,gravel,wood}.webp`：512×512，内部取样后四象限镜像，左右/上下边缘匹配；WebP 92。它是低成本重复纹理，不是经过完整材质烘焙的 PBR 贴图。
- `barrier.png` / `ramp.png` / `slow-strip.png` / `curb.png`：独立 RGBA。保留主体连通域、清除漂浮透明噪声、轻微收边、缩小后抗锯齿；路障、跳台和路沿边界留透明余量；缓速带后续精修为开放两端、完全铺满的矩形材质。组件不自带大面积地面投影，样板统一添加。
- `icon-boost.png` / `icon-jump.png`：从同套车辆设备局部派生，用于赛道装置按钮。
- `shadow.svg` / `boost-flame.svg` / `landing-ring.svg` / `finish-line.svg`：本轮绘制的独立矢量效果/标线。尾焰、落地气圈已接入既有样板演示动画；未修改游戏物理。效果无外部依赖。

### 原图与可重复处理

三张 1254×1254 AI 原图保留在 `art-assets/track-kit/originals/`，原字节不改。车辆原图是粉色底；组件原图实际返回了透明底，处理脚本按真实 alpha 去噪，而不是假定提示词被完全执行。原图四格部件没有严格等分，组件裁切使用明确矩形，不按四等分生硬切断。

在游戏 worktree 根目录运行（sharp/Playwright 只用于离线处理，不加入项目依赖）：

```sh
SHARP_MODULE=/absolute/path/to/sharp node tools/mini-garage-art/build-track-kit.cjs
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tools/mini-garage-art/capture-kit-board.cjs
```

第一条重建 PNG/WebP 派生素材；第二条用 Chrome 从实际素材生成总览图，`CHROME_PATH` 可覆盖默认 macOS Chrome 路径。四份 SVG 源码手工保留，不需重新生成。

不把 `originals/`、截图或离线工具作为最终运行时必需资源。图像生成来源已记录，但本轮不作独占版权或商业授权已完成的保证，正式交付仍应确认服务条款与授权记录。

## 尚待评审 / 实施注意

1. 重点请用户评审实际赛道截图的整体密度与部件尺度，不只看放大的素材板。材料观感属于同一方向，不等于用户已经确认品质。
2. 首页车与新俯视车保留相同配色和车型语言，但灯、玻璃、设备结构不是同一 3D 模型的严格多视图输出，仍需定稿时对齐。设备从俯视能清楚区分，但目前不是可装配骨骼模型。
3. 纹理采用镜像重复，会出现局部对称花纹；若长时间滚动评审中重复感明显，再制作更多非镜像过渡/变体，不以高频噪声遮掩。
4. 当前三个场景只是材质代表段，不声称已经按关卡模型铺出完整 2 组/4 组跳台路线。生成出的路沿圆角段仍依靠细间隙拼接与连续底座衔接。
5. 真正接入可玩版时沿用模型的碰撞体、跳台/缓速带位置与共同腾空规则；不得根据素材边界重定义玩法。分离物理与绘制，并补资源载入、生命周期、缩放/内存、触摸、iPhone Safari 真机检查。
6. 等品质确认后再展开全关卡渲染和生产资源打包；授权、重玩、宿主、音频、PWA 缓存等仍未完成。此次不合并 main。
