你是一名资深小学英语老师兼题库工程师，要为「星星答题」App 生成一份可直接导入的英文题库 JSON。请严格按以下要求出题并输出。

## 一、任务

- 学习者：【年级/水平，如：小学三年级，剑桥少儿英语 Starters 水平】
- 主题/词表：【如：人教版 PEP 四年级上册 Unit 1–3，或直接粘贴目标词表】
- 规模：共约【题目总数】题，覆盖目标词表中的词，每个词出 1–3 种题型（zh2en / en2zh / cloze）
- 难度分布：约 30% 难度 1、40% 难度 2、30% 难度 3

## 二、输出格式（硬性约束，任何一条不满足都无法导入）

### 顶层结构（5 个字段一个都不能少）

| 字段 | 要求 |
|---|---|
| `version` | 必须是字符串 `"3.0"`（现役学习文件契约；2.0 仍可导入，但新产出一律写 3.0） |
| `exportedAt` | ISO 8601 时间字符串，如 `"2026-09-03T08:00:00.000Z"`（用生成时刻） |
| `questionPool` | 题目数组 |
| `flagged` | 固定空对象 `{}` |
| `questionResults` | 固定空对象 `{}` |

### 每道题的字段（5 必填 + 2 可选）

| 字段 | 要求 |
|---|---|
| `id` | 6 位数字字符串，从 `"000001"` 起连续递增，全局唯一 |
| `type` | 只能是 `"zh2en"` / `"en2zh"` / `"cloze"` 三者之一 |
| `prompt` | 非空字符串；cloze 题在挖空处写恰好三个下划线 `___` |
| `options` | 恰好 4 个字符串，每个非空且互不重复 |
| `answerIndex` | 0–3 的整数，必须指向正确选项的**下标** |
| `wordId`（建议必写） | 该题考查的目标词：zh2en/en2zh = 正确英文单词；cloze = 填入挖空处的正确答案词（与正确选项逐字一致）。导入允许缺省，但同词多题的分组靠它，请始终写出 |
| `difficulty`（可选） | 只能是 1 / 2 / 3；不写会被按 3（最难）处理，所以请务必明确写出 |

### 三种题型示例

- **zh2en**：中文词干 + 4 个英文选项 → `prompt: "博物馆"`，`options: ["library","hospital","museum","cinema"]`，`answerIndex: 2`，`wordId: "museum"`
- **en2zh**：英文词干 + 4 个中文选项 → `prompt: "island"`，`options: ["岛屿","陆地","沙滩","森林"]`，`answerIndex: 0`，`wordId: "island"`
- **cloze**：英文句子挖空 + 4 个英文词 → `prompt: "We ___ the museum last Sunday."`，`options: ["visit","visited","visits","visiting"]`，`answerIndex: 1`，`wordId: "visited"`（`last Sunday` 是锁定线索：只有过去式成立）

### 同词多题

同一目标词的多种题型**共用同一个 `wordId`**（如 "museum" 同时有 zh2en 和 cloze 两题，`wordId` 都是 `"museum"`，且 cloze 句子必须挖 museum 这个词本身）。App 每轮抽题同词至多出 1 题，多题型让不同轮次换着考。

## 三、出题质量要求

1. **answerIndex 一票否决**：导入程序只认下标、不校验答案对错。`answerIndex` 指向的选项必须与 `wordId` 完全匹配（zh2en/en2zh = 那个正确英文词/其释义；cloze = 能正确填入挖空的词）。
2. **cloze 必须唯一可解（单选题底线）**：正确答案要被题干上下文**唯一锁定**——每个干扰项代入句子后都必须能被明确判错（语法不通 / 搭配不成立 / 与句中信息矛盾）。若四个选项填进去句子都通顺（典型如挖形容词、选项全是说得通的形容词），此题不合格：必须改写题干补锁定线索（时间状语、场景、对比、搭配对象、时态/单复数标志等），或换干扰项。
   - 反例：`The dog is ___.` + `["big","cute","black","fast"]` → 没有上下文，四个都对，不合格
   - 正例（时态锁定）：`We ___ the museum last Sunday.` → 只有 `visited` 成立
   - 正例（语义锁定）：`We swam in the sea and played on the ___.` → 只有 `beach` 与「海边游泳玩耍」搭配成立
3. **干扰项要有迷惑性但不正确**：优先用近形词（delicious/dangerous）、同类词（museum/library/cinema）、易混词形（visit/visits/visited/visiting），避免一眼排除的荒谬选项。
4. **词形逐字一致**：cloze 挖空处与正确选项的词形完全一致（大小写、单复数、时态变形都要对上）；挖空尽量不要落在句首。
5. **句子地道**、难度匹配学习者水平，句长适中，不出现超纲语法。
6. **禁止同义词当干扰项**（zh2en / en2zh 同样适用）：中文词干若对应多个正确英文词（如"美丽的"→ beautiful / pretty 都对），或英文词干对应多个正确中文释义（"岛屿/岛"），这些同义项一律不得出现在 `options` 里——它们会让题出现多个正确答案。
7. **忠于词表**：正确答案词都在目标词表内，不生造词。

## 四、输出要求

1. 只输出一个合法 JSON 对象：无注释、无尾逗号、无解释文字，不要用 markdown 代码块包裹。
2. 中文直接输出汉字，不要转义成 `\uXXXX`。
3. 输出前逐题自检：`id` 连续唯一；`options` 恰好 4 个非空不重复；`answerIndex` 指向的选项 == `wordId` 对应的正确答案；cloze 的 `prompt` 含恰好一处 `___`；`difficulty` 都是 1/2/3。
4. cloze 额外自检（最重要）：把每道 cloze 的 3 个干扰项**逐一代入句子**，每个都要能说出明确错因（语法不通 / 搭配不成立 / 与句中信息矛盾）；只要有一个干扰项代入后"也说得通"，就改写题干补锁定线索或换掉该干扰项。
