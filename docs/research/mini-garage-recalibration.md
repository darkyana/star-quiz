# 迷你车库：敏捷小游戏基线重校准

> 2026-09-14 UTC。状态：代码及自动验证完成，浏览器实玩／真人微调待做；未发布。
> 用户要求：先参照知名原作建立敏捷基线，再试玩微调；已明确选择同步延长赛道、保持约一分钟一局。原 5173 服务停止后，用户选择暂不重启。

## 1. 这轮与上一轮不同在哪里

上一轮报告提出的 25→40 候选仍偏保守，且没有充分参照知名原作。这次不在旧慢档上微调，而是以 **Chrome Dino、Canabalt 的原作源码时间尺度** 为主要基准，以 **Microsoft 官方 Surf Lite** 为连续转向辅助对照，重新配置前进、转向、装置和减速。

这是有来源依据的本游戏设计映射，**不是宣称存在统一行业参数，也不是已经证明适合所有儿童**。源码推算的“边缘出现→碰撞”时间，不等于玩家已看清障碍后的有效反应时间。

## 3. 已落地的映射

运行代码：[index.html / GarageModel.tuning](../../public/games/mini-garage-prototype/index.html)。原先散落的主要可调参数集中到 tuning，方便后续微调；投影与美术不变。

| 参数 | 旧版 | 新基线 |
|---|---:|---:|
| 公路胎／硬地目标速度 | 25→32 | **80→100** 世界单位/秒 |
| 越野胎／硬地目标速度 | 21→26.88 | 74→92.5 |
| 公路胎／软地目标速度 | 13→16.64 | 64→80 |
| 越野胎／软地目标速度 | 21.5→27.52 | 78→97.5 |
| 热身／达到成熟倍率 | 12／50 秒 | **3／24 秒**，平滑增长 |
| 公路硬地几何前视 | 4.86→3.8 秒 | **1.52→1.216 秒** |
| 公路硬地成熟屏高速度 | .20 屏/秒 | .625 屏/秒 |
| 直道常规相邻障碍通过周期 | 成熟时约 3.13–3.75 秒 | 成熟时 **1–1.2 秒**；段间空档 2.6 秒 |
| 加速 | ×1.6，2 秒，冷却 7 秒 | ×1.25，1.25 秒，冷却 5 秒；公路硬地最大目标 125，几何前视约 .973 秒 |
| 满幅横移上限 | .9×grip | **2.4×grip** |
| 公路胎软地／越野胎 grip | .48／.86 | .75／.92 |
| 拖动跟随增益 | 7 | 12，仍限幅和平滑跟随，不瞬移 |
| 跳跃蓄力／腾空／冷却 | .12／1.8／5 秒 | **.10／.65／3 秒**，提示窗口同步调整 |
| 碰撞保留速度 | 28% | **60%**；正常目标恢复响应系数 2→4 |
| 缓速带速度／完整着地用时 | 4／约 3.5 秒 | **28／约 .5 秒** |
| 路外目标速度保留 | 48% | 75%；仍有惩罚，避免长期爬行 |

说明：

- 视野仍为 160 单位/画布高，车基线 .76H，前方几何距离 121.6；由 `121.6 / 1.52 = 80`、`121.6 / 1.216 = 100` 反推本游戏速度。目标落在原作参照较宽松的一端，正常速度不直接使用 .65 秒的高难截面。
- 前视为恒速几何切片；起步和装置切换时实际速度平滑变化。没有实际测量远端障碍何时可被人辨认。
- 直道 1–1.2 秒是相邻路障经过周期，不保证每只都必须换边。混合路线还有跳台、路面变化和较长空段，不能用一个统一“刷怪频率”概括。
- 横移 .6 归一化距离的满幅运动学下限，从旧版硬地 .67／公路胎软地 1.39 秒降到 .25／.33 秒；自动测试另验证带拖动缓动、道路移动的接近目标耗时不超过 .5 秒。不是设备端到端触摸延迟或儿童实测。
- 跳跃 .65 秒接近短动作量级，同时保证最慢正常软地也能覆盖跳台到缓速带末端的 22 单位距离。保留地面才可重跳、冷却与蓄力状态。
- 加速倍率降低不表示新加速更慢：新公路硬地加速目标上限 125，旧版只有 51.2。

## 4. 保留约一分钟，而不是缩短权益

用户已选择保持单局时长：将每条原 1800 单位编排重复三段，成为 **5400 单位连续路线**；路面、障碍、跳台、缓速带同步复制，间距不放大。不是三条全新设计的关卡，也不是只拉长空白路面。

- 直道 45 个障碍；碎石／工坊各 39 个。
- 碎石 6 组、工坊 12 组跳台与缓速带。
- 超过 32 个事件后，旧位掩码会索引重叠，因此改为各局独立的 Set，并测试第三段的每次碰撞只计一次。
- 进度条、终点、详情和文案改为读模型长度。路面预览仍只显示一个模板，并明确重复三段，避免手机上塞进 15 个小标签。
- 碰障不判负，原四种配置、三种路线保留。**不改价格、星星、授权协议，也不改美术和音效。**

## 5. 自动验证结果

### 模型完赛基线

调用本地实际 `simulate(tire, gadget, track, 'ramps')`，固定 1/120 秒步长。该策略会避障、对准跳台，并按条件使用加速；这是自动驾驶，不是孩子试玩：

| 赛道 | 公路胎＋跳跃 | 公路胎＋加速 | 越野胎＋跳跃 | 越野胎＋加速 |
|---|---:|---:|---:|---:|
| 直道 | 56.94s | 53.70s | 61.32s | 57.77s |
| 碎石 | 66.82s | 62.96s | 59.12s | 56.19s |
| 工坊 | 62.77s | 59.24s | 60.02s | 56.78s |

这 12 组均零碰撞、命中全部跳台并跨过全部缓速带，所有障碍逐一计入。自动策略也修正为优先完成近处跳台，不提前为跳台后方的障碍转向；其障碍观察距离限制到几何前视范围。

### 独立连续路径检查

测试中的另一策略每 100ms 观察一次、只看前方 121.6 单位，指令再延迟 180ms 生效，使用与拖动相同的限幅缓动，不主动跳跃。三路线×两轮胎覆盖正常装置冷却，以及**持续满加速**的保守包络，共 12 组；全部零碰撞、零路外，命中全部跳台并跨过全部带。

它证明这些条件下存在一条可执行路径，**不是所有起始位置／误操作都能挽救的形式证明，也不是儿童反应时间研究**。180ms 是测试假设，不是要求孩子达到的门槛。

## 6. 后续微调的起点

本轮交付的是待试玩的敏捷基线，不继续无依据地来回改数字。服务恢复后首先测：

1. 手机／iPad 上远端路障和跳台能否及时辨认，正常与加速时分别看。
2. 同一配置完整跑约一分钟，检查是否需持续过量纠正方向；转向太敏感时优先调横移／拖动，而非立即把前速降回旧档。
3. 短跳提示能否跟得上，减速是否短促而非“没感觉”；保留零件选择收益。
4. 根据你的实际试玩再微调速度、障碍周期或动作，不同时改变所有轴。
