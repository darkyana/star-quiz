# 教学偏好与工作笔记

## 教学偏好（老板已确认的口径）

- **中文授课**：全部课程、术语表、小测均为中文；术语首次出现时可括注英文原名（如「路由（Routes）」），方便对照 Cloudflare 面板。
- **零部署经验**：教学对象是「历次部署都由 AI 一步步带着操作的人」。任何云服务名词首次出现都要当新词讲，不预设。
- **建立的是地图感**：老板要的是「每一步在干嘛」的地图感——请求从孩子设备到页面出现（及将来数据同步），路上每一站是谁、各管哪段。
- **目标判断力，非运维技能**：课程止步于「能看懂步骤、能分层判断问题、能评估方案」；不教独立操作 Cloudflare 面板或 wrangler 命令。
- **不教抽象云知识**：一切概念都锚定 star_quest 的真实拼图（现役部署 + ADR 0003 锁定栈），不搞通用云课程。
- **课程形态**：短课（单课 5–10 分钟、单一收获）+ 小测（assets/quiz.js 即时反馈）+ 术语表（reference/glossary.html）。
- **时间态必须诚实**：现役 = Pages 链路天天在跑；Worker/D1/Cron = 将来态（P0 #119 未落）。课里说「将来」就是还没上。
- **后续课程**：由老板用 teach 技能按需续课（本工作区首票只交付地基 + 第一课）。

## 工作笔记（teach 会话维护）

- **术语表预置与「学过才收」规则的张力**：GLOSSARY-FORMAT 约定「用户学过、能正确使用后才收进术语表」；但票 #89 面要求预置 11 词条。处理：票面契约优先，预置全部 11 词条作为「判断力对照表」（每条注明在 star_quest 里的现役/将来对应）；老板学完相应课程后，由 teach 会话按其真实理解**确认或修订**词条，使其逐步回归「学过才收」的精神。
- **域名指代**：现役部署的自定义域名的具体名字仓库里没有记录，所有材料一律用「你的自定义域名」指代，不编造。
- **外链口径**：RESOURCES.md 每条链接均经真实可达验证（2026-09-02 验证）；正文引用只从 RESOURCES.md 取链接。
