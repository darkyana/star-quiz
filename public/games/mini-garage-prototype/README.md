# 迷你车库 · 游戏侧接入说明

本目录按上级 `public/games/README.md` 的生命周期协议 v1 实现。保留三条赛道、四种搭配及玩具美术；现行主 App 槽位由 `src/data/playable-games.ts` 引用本目录，账务由宿主负责。

## 运行与交付

- 将整个目录复制到静态站点任意子路径，通过 HTTP(S) 打开 `index.html`；无需构建。使用 ES modules，不支持 `file://` 双击。
- 顶层打开：独立试玩，不向宿主发送消息。
- 同源 iframe：必须授权后触摸「触摸出发」才开跑。配车不计入局内用时。
- `host.html`：独立演示宿主，先注册监听后加载 iframe；手动确认每一局、退出时销毁 iframe，不扣星。
- 使用仓库 Vite 开发服务时，小游戏路径为 `/games/mini-garage-prototype/index.html`，演示宿主为同目录 `host.html`。端口与服务是否在线须现场确认；不要把历史 4173 端口视为当前仓库服务。
- 全部加载仅在本目录内；无接口、第三方依赖、网络上报、Service Worker、宿主 DOM 或存储访问。加载后资源在内存中，可断网继续玩；冷启动仍需静态资源可达。

## 生命周期与防御

`lifecycle.js` 管理 `waiting → authorized → playing → ended`，重玩回到 `waiting`，退出进入终态 `exited`。

- 每次文档加载生成随机 instanceId；22 份赛中/配车资源全部加载成功后仅发一次 `ready`。失败可重试，不提前报就绪。
- 所有消息恰好六字段：channel、version、type、instanceId、requestId、roundId。
- 接收只信任同源 `window.parent`，发送仅用 `location.origin`，不使用 `*`。
- 只接受当前等待请求的 `start`；拒绝错来源、错版本/channel/实例、旧请求、复用 roundId、多余或缺少字段，以及已授权/游玩时的重复授权。
- `start` 不自动开始比赛，只启用「触摸出发」。点击该按钮后开始计时。
- 冲线仅发一次 `ended`。重玩保留配置回车库，可重新选车/赛道，发送递增请求号和上一局 roundId；宿主签发全新 roundId 前不得开跑。
- 嵌入模式的「退出游戏」发送当前 requestId / roundId：初次授权前为 null，等待重玩时为新请求号和上一局 roundId。不允许通过「返回车库」绕过授权。
- 不设超时重发，不恢复已退出或刷新丢失的局，不自行处理账务。

## 体验与兼容

- 手机式单列，以 iframe 视口布局；iPad 沿用同一流程。
- 碰障仅减速，不判负；当前采用敏捷重校准基线：3 秒热身，24 秒达到最高正常倍率，参数集中在 `GarageModel.tuning`。不再沿用旧版慢速模型冻结约定。
- 隐藏页面 / 失焦自动暂停，回来触摸继续；暂停期间时间、冷却与车身状态不前进。
- 触摸拖动、左右按钮和双指装置操作；无需键盘。
- 无音频、无持久化；禁用存储不影响游玩。试跑记录只在内存中。若以后增加 WebAudio，必须在游戏内真实触摸后激活，失败不得阻塞游玩。
- 首页入口使用用户确认的极简侧面小车贴纸：`icon.png` 为 512×512 透明 PNG，`icon.svg` 为内嵌同一 PNG 的自包含 SVG（不是重绘的纯矢量图）。方形 viewBox，无外层描边；宿主按协议引用 `icon.svg`。获批生成原图按原字节保存在 `docs/game/mini-garage/entry-sticker/approved-original.png`。
- 移除 Safari 15.4 不支持的 Canvas `roundRect` 调用，使用 `arcTo`；视口保留 `vh` 回退，尊重减少动态效果。

## 敏捷基线（待真人微调）

- 参照 Chrome Dino、Canabalt 的源码时间尺度；微软官方 Surf Lite 为连续转向辅助对照。是本游戏的映射设计，不是行业统一参数或儿童适宜性结论。
- 公路胎硬地普通速度仍为 80→100 世界单位/秒；现有前视 121.6 单位，普通几何预览约 1.52→1.22 秒。加速更新为 1.6 倍、持续 1 秒、冷却 5 秒：公路硬地成熟目标上限 160，几何前视约 .76 秒。加速响应系数 8，结束后用原响应系数 4 平滑回落。
- 横移上限为 `2.4 × grip`，公路胎软地 grip=.75，越野胎=.92；拖动仍为限幅平滑跟随，不瞬移。
- 弹跳蓄力 .10 秒、腾空 .65 秒、冷却 3 秒；提示窗口同步缩短。碰撞保留 60% 速度，缓速带上限 28（14 单位约半秒）。
- 每条 1800 单位的原有布局重复三段，合计 5400；障碍为直道 45 个、其他各 39 个；碎石／工坊分别 6／12 组跳台与缓速带。事件使用 Set，不受旧 32 位掩码限制。路面与全部事件同步延长。
- 模型自动驾驶 12 种配置约 50–67 秒完赛；不是保证所有玩家固定一分钟。普通速度、转向、赛道长度、价格、授权与扣星规则未在本轮加速反馈中改变。
- 初始重校准研究见 `docs/research/mini-garage-recalibration.md`；其中 1.25 倍加速参数是历史基线，现行值以本说明与 `GarageModel.tuning` 为准。

## 加速反馈

- 真正提速只改变模型推进距离 `s.z`；道路纹理、路缘、路障、跳台、缓速带仍用同一个投影，没有单独加快路面贴图造成打滑。
- 冲刺时在道路外加入 8 个近景木质件和 10 条速度线，复用玩具素材和已有颜色；装饰层按 1.7 倍世界位移掠过，并用曲线路面反向裁切，不遮挡可行驶区域或碰撞物。数量固定，无随机粒子堆积或新增素材下载。
- 车尾喷焰更长，按钮立即显示「冲刺中！」。视觉约 .12 秒进入、冲刺结束后 .28 秒淡出；物理速度另行平滑回落。所有视觉相位只读模拟时间和位置，没有独立计时器；暂停冻结，重开不继承上局效果。
- 「减少动态效果」关闭额外近景和速度线、取消喷焰尺寸脉动，保留稳定小喷焰与文字反馈；不改变实际速度和碰撞判定。不增加模糊、镜头抖动、缩放或音频。
- 选值检查：1.6 倍通过有限视野＋延迟操作的全路线检查（含持续峰值的保守条件）；探索的 1.7 倍在工坊越野胎持续峰值条件下漏掉两个跳台，因此没有采用。该自动策略证明存在可行路径，不代表孩子体验已经验收。

## 验证

在仓库根执行：

```sh
node --test tools/mini-garage-pacing.test.mjs tools/mini-garage-boost.test.mjs tools/mini-garage-contract.test.mjs tools/mini-garage-assets.test.mjs
# 需要可用 Playwright 模块与系统 Chrome，复用现有 HTTP 服务：
PLAYWRIGHT_MODULE=/path/to/playwright node tools/mini-garage-art/verify-playable.cjs
# 可用 PREVIEW_URL 指向小游戏目录的 HTTP(S) URL（以 / 结尾）
# 无需启动服务的离线浏览器快照：正常／加速／减少动态效果 × 手机／平板
PLAYWRIGHT_MODULE=/path/to/playwright node tools/mini-garage-boost-preview.mjs
# 输出到临时目录；可用 REVIEW_DIR 指定快照目录
```

- 协议/DOM 自动测试：完整链路、非法消息、各阶段退出、重复结束、素材失败、独立试玩、暂停与配置模拟。
- 节奏回归：速度／视野、全配置局长、重复事件唯一性、软地横移、减速恢复、短跳与冷却；有限视野＋延迟操作策略覆盖所有路线及持续满加速包络。原始美术与资源契约仍独立验证。
- Chrome 浏览器验证：320×568、390×844、844×390、1024×768 四视口的三路线；真实触摸事件、暂停/继续、禁用存储、加载后断网、禁用 roundRect、嵌入两轮授权与退出销毁；检查脚本与资源错误。
- 加速回归额外检查真实速度上升与释放、普通速度不变、每局视觉重置、暂停冻结、渲染不写模型；相同世界位置下，除喷焰／路外装饰外的绘制指令保持一致。
- **本轮边界**：已通过模型／DOM／资源验证，并用真实 Chrome 的离线请求映射检查 390×844 与 1024×768 的正常／加速／减少动态效果六张画布快照。不启动替代服务；快照冻结模型状态，不是实际 RAF 性能、完整比赛、真机多指手感或线上验收。原 5173 服务仍未重启。
- 设计检测器报告原有小字、低对比度等警告（位于未修改的 CSS／配车界面）；本轮保留既有样式，不把局部加速效果扩成整页视觉重构。
