# 滑板少年

俯视纵向卷轴三车道小游戏：滑动或点按换道，躲路障、接星星，三条命，连击计分、速度递增。无跳跃、无道具、无键盘依赖。此目录为自包含静态资产，不导入主产品代码，不读取经济账本。

## 独立试玩

在已有开发环境或静态部署地址下打开 `games/skate-boy/index.html`。ES modules 需要 HTTP(S)，不使用 file://。

- `index.html`：顶层直接试玩；这是开发/资产入口，不在孩子首页开放免费入口。
- `host.html`：嵌入生命周期演示。明确不收费、不连接经济系统，每局需要人工点击“确认试玩一局”。
- 主产品付费接入应使用 `index.html` 的嵌入模式，不使用演示宿主来记账。

每个资源引用使用相对路径，整个目录可随现有静态站点发布。单 HTML 不是硬约束。

## 玩法与声音

滑动左右换道，也可直接点按左、中、右车道。三次碰撞后结算；沿途收集星星仅增加游戏分数，不增加主产品星星。最高分只保存到本机 `skate-boy.v1.best`，不记录每局历史，也不跨设备同步。

收到嵌入开局授权后会显示“触摸出发”就绪层。此触摸只是启动已授权局，并在 iframe 内取得真实用户激活来启用 WebAudio，不是第二次兑换或收费。音频 resume 不作为开局等待条件；无法出声时下一次真实触摸会重试，不能因此卡住已付费局。尚需真实 iPad Safari 试听，自动化环境不证明声音已经可用。

## 生命周期协议 v1

游戏检测自己是否在 iframe 中。只支持同源宿主；宿主与游戏双方都必须校验消息 origin 和 source，不使用通配目标源。

每条消息恰好有六个字段：

| 字段 | 含义 |
| --- | --- |
| channel | 恒为 `skate-boy` |
| version | 数字 `1` |
| type | `ready` / `start` / `ended` / `replay-request` / `exit` |
| instanceId | 游戏文档本次创建的实例标识 |
| requestId | 实例的请求序号，初次为 `${instanceId}:1`，重玩递增 |
| roundId | 宿主签发的非空、不可复用的局标识；初次 ready 为 null |

流程：

1. 宿主先注册接收监听，再加载 iframe，避免缓存游戏比监听器更早就绪。
2. 游戏发送 `ready`。宿主核对来源及完整形状，绑定当前 frame、实例和初次请求。ready 本身不能作为收费或自动开局的依据。
3. 人工确认后，生产宿主先执行自己的时间/余额门禁与扣费；成功后签发新 roundId，发送 `start`，其余关联字段与当前请求一致。演示宿主只模拟人工授权，不记账。
4. 游戏接收符合当前 waiting 状态、请求和未使用局标识的授权，进入 authorized；真实触摸后进入 playing。旧请求、复用局、游玩中重复授权均不可开新局。
5. 游戏结束时发送一次 `ended`，包含本局 requestId/roundId。宿主只记生命周期状态，不接收分数。
6. 用户选择重玩，游戏发送一次 `replay-request`，requestId 加一，但 roundId 仍指向刚结束的一局。宿主只在正确前局结束状态接受它；重新人工确认与付费后，再发送全新的 roundId。游戏不能在嵌入模式自行免费重开。
7. `exit` 终结当前实例，宿主退出游戏展示。重建 iframe 是新实例，旧实例消息不得被后续局接受。

消息不得携带价格、余额、分数、流水或孩子数据。静态资源入口不是防篡改权限服务器，本协议不承诺阻止开发者工具或直接访问静态资源。

### Spec 缺口与保守落地

- 连击细则未给定：每星 10 分，第 3 颗起固定双倍，漏接或碰撞归零；速度与出物间隔渐进并封顶，不设强制结束时限。
- iPad 音频需要 iframe 内真实手势：收到授权后先等待“触摸出发”，不再次收费；声音失败不阻塞游玩。
- 游戏自身 HUD/就绪层使用独立 CSS 视觉令牌，不引入主 App 组件。减少动态效果时停装饰街景滚动、粒子与摇晃，保留必要障碍移动。
- 尚未做 iPad Safari 真机触控/出声/横竖屏/人类完整试玩，未做已发布 Pages 资源验收；这些不能由自动化通过代替。

## 自动化与初步时长校准

已有验收边界测试独立玩法、生命周期以及演示宿主的人工授权/重玩/拒绝非法消息/清理监听。测试只观察公开输入输出，不锁 Canvas 逐条绘制命令。通过项目既有 vitest 执行相关 skate-boy 验收测试即可；不新增浏览器自动化框架。

开发中以公共游戏接口做过 100 个固定种子的只读模拟：

| 简单模拟策略 | 单局中位 | 90 分位 |
| --- | --- | --- |
| 固定中道不操作 | 30.45 秒 | 48.57 秒 |
| 近身物体 40% 概率正确反应 | 41.17 秒 | 71.97 秒 |
| 近身物体 60% 概率正确反应 | 58.22 秒 | 98.80 秒 |
| 近身物体 80% 概率正确反应 | 102.42 秒 | 151.58 秒 |

正确反应策略：实体接近玩家前，星星切对应道、障碍切相邻道。此数据只说明模型对反应熟练度的趋势，**不是人类试玩，不是真实 iPad 验收，也不保证所有玩家单局均为 1–3 分钟**。最终手感、时长、声音、屏幕适配和视觉冲击感由真机试玩校准。
